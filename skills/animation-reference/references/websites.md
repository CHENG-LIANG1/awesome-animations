# Animation Reference Websites

Use this catalog to choose a source based on the question. Links were reviewed on 2026-08-26; access rules and paid features may change.

## UI Motion and Runnable Patterns

### 60fps

- URL: https://60fps.design/
- Best for: identifying polished mobile and product micro-interactions from a visual idea.
- Useful filters: Morph, Shared Element, Spring Physics, Stagger, Parallax, Reveal, Scroll, Drag, Swipe, Hold, Loading, Tabs, Toast, Text, and Zoom.
- Search here first when the user says “I can picture it but cannot name it.”

### Motion Examples

- URL: https://motion.dev/examples
- Best for: runnable React, JavaScript, and Vue motion patterns with accurate technical names.
- Useful categories: buttons, carousels, cursors, dialogs, interactions, layout animation, loading, navigation, page transitions, scroll, and text.
- Prefer this when the next step is implementation. Some source examples may require Motion+.

### Animista

- URL: https://animista.net/
- Best for: common CSS entrances, exits, attention effects, backgrounds, text effects, and basic transforms.
- The playground exposes duration, timing function, delay, iteration, direction, and fill mode.
- Prefer this for lightweight effects that do not require layout choreography or gesture physics.

## Real Product Flows

### Mobbin

- URL: https://mobbin.com/
- Best for: real mobile and web product screens, flows, and recorded micro-interactions.
- Prefer this when context matters: onboarding, checkout, subscription, settings, search, empty states, and other end-to-end product behavior.

### Page Flows

- URL: https://pageflows.com/
- Best for: video recordings of real product journeys such as sign-up, upgrade, cancellation, checkout, and first-run experiences.
- Prefer this when isolated screenshots cannot explain sequence, pacing, or state transitions.

## Experimental and Editorial Web Motion

### Codrops

- URL: https://tympanus.net/codrops/
- Motion highlights: https://tympanus.net/codrops/category/motion-highlights/
- Best for: creative page transitions, image effects, typography, pointer interaction, WebGL, Three.js, and GSAP experiments.
- Prefer this when the user wants a demo or tutorial rather than only a finished-site showcase.

### GSAP Showcase

- URL: https://gsap.com/showcase/
- Best for: ambitious production websites using scroll storytelling, pinning, timelines, layered transitions, SVG, and 3D motion.
- Prefer this to explore what is possible with complex web animation; verify a showcased site's implementation before attributing its effects to a particular technique.

### HOVERSTAT.ES

- URL: https://www.hoverstat.es/
- Best for: unconventional websites experimenting with navigation, layout, interaction, and content.
- Prefer this for alternative art, culture, portfolio, and editorial motion references.

### Godly

- URL: https://godly.design/
- Best for: a broad, curated gallery of modern web, app, UI, and visual design.
- Prefer this for fast visual exploration when the animation category is not yet known.

## Routing Guide

| Need | Start with | Then use |
| --- | --- | --- |
| Name an app micro-interaction | 60fps | Mobbin |
| Understand a complete product flow | Page Flows | Mobbin |
| Find a code-oriented example | Motion Examples | Animista |
| Find a creative website transition | Codrops | GSAP Showcase |
| Explore unusual interactive sites | HOVERSTAT.ES | Godly |

When a reference is selected, save its direct item URL when possible, plus a screenshot or short recording. Gallery homepages change over time.
